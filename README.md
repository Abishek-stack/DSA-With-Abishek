# DSA-With-Abishek

This repository contains my daily practice of Data Structures and Algorithms using C++.  
I am using this repo to prepare for coding interviews and campus placements.

## Goals

- Solve 300+ LeetCode problems
- Master core DSA topics
- Maintain consistent daily practice
- Prepare for software engineering interviews
  
## Topics Covered
- Arrays
- Linked List
- Hashing
- Trees
- Graphs
- Dynamic Programming
- Greedy
- Searching & Sorting

Each problem includes:
- Clear logic
- Optimized approach
- Time and Space complexity

This repository will be updated regularly as I continue my DSA journey.
